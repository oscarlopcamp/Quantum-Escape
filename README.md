# 🎮 Quantum Escape

**Versión 2.0 | Videojuego cooperativo 2D sobre computación cuántica**

Quantum Escape es un videojuego educativo que introduce conceptos fundamentales de la computación cuántica mediante desafíos interactivos y mecánicas cooperativas.

## 🚀 Jugar en línea

**[▶ JUGAR QUANTUM ESCAPE](https://oscarlopcamp.github.io/Quantum-Escape/)**

El juego se ejecuta directamente en el navegador, sin necesidad de descargarlo o instalar Godot.

## ⚛️ Conceptos cuánticos

- Superposición
- Entrelazamiento
- Interferencia
- Medición

## 🕹️ Características

- Videojuego 2D.
- Mecánicas cooperativas.
- Desafíos inspirados en principios de computación cuántica.
- Versión web desarrollada con Godot.
